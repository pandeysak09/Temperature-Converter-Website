# Temperature-Converter-Website
The Temperature Converter Website is a simple and user-friendly web application developed using HTML5, CSS3, and JavaScript. It allows users to convert temperature values between Celsius (°C), Fahrenheit (°F), and Kelvin (K).
The application provides input validation to ensure that only valid numeric values are accepted. It also checks for temperatures below absolute zero and displays an appropriate error message. The interface is clean, responsive, and easy to use on both desktop and mobile devices.

This project demonstrates fundamental web development concepts, including HTML structure, CSS styling, responsive design, JavaScript DOM manipulation, event handling, input validation, and mathematical calculations.
